# 매매 로직 변경 프로토콜

실계좌로 도는 시스템이다. **순서를 지켜라.** 각 단계는 실제 사고에서 나왔다.

## 0. 지금 바꿔도 되는 때인가

```bash
Get-Process python -ErrorAction SilentlyContinue
```

- 봇이 살아 있고 **09:00~15:30**이면 → 🔴 **매매 로직 파일을 고치지 마라.** 장 마감 후로 미룬다.
- `ui/` · `docs/` · `test_*.py` 는 장중에도 안전하다 (`ui/`는 `core/`·`main.py`를 import하지 않는다).
- 정지가 필요하면 `STOP_SIGNAL` 파일 생성 → 종료 확인(`안녕히` 로그) → **STOP_SIGNAL 잔존 여부 확인**.

## 1. 근거를 먼저 읽어라 🔴

```
docs/EXPECTED_VALUES_RATIONALE.md   ← 기대값 44개 각각의 근거·실측·롤백
```

**이 프로젝트가 반복해서 밟은 사고가 "근거를 모른 채 값을 되돌리는 것"이다.**
예: 본전스톱 무장 문턱을 낮추면 4개 바닥 열 **전부** 나빠진다(08-13 격자). 값만 보면 알 수 없다.

## 2. 데이터로 정하는 값이면 `stats-referee`를 먼저 통과시켜라

백테스트·격자·반사실로 값을 고르려 한다면, **숫자를 믿기 전에** 방법론 심판을 호출한다.
시간균등 기준선 / 독립표본 / 날짜별 분해 / 양가정 / 소수 대박 의존 — 이 중 하나만 어겨도 결론이 뒤집힌 이력이 있다.

⚠️ 사용자가 지정한 값이면 이 단계는 건너뛴다. 다만 **"백테스트 판정 불가였다"는 사실은 기록에 남긴다**(물타기 사례).

## 3. 구현 — 단일 창구에만 넣어라

| 새 조건의 성격 | 넣을 곳 |
|---|---|
| 전면 차단 | `_entry_block_reason()` |
| 등락률 상·하한, 주가 상한 | `_entry_change_reject()` |
| 숙성·진입 유효창 | `_entry_delay_reject()` |
| 발사 판정 | `_fire_gate()` |

🔴 **호출부를 늘리지 마라.** 같은 규칙이 여러 경로에 복제되는 것이 이 프로젝트 실패 1위다.

- surgical 패치 우선(찾기→교체). 파일 전체 재작성 금지.
- 파일 삭제 금지 — `_legacy` 접미사로 보존.
- 끄는 기능이면 **로직·상수를 지우지 말고** 플래그만 False로. 배선 테스트는 롤백 컨텍스트로 감싼다.

## 4. `edge-auditor` 호출 — 산재 확인

무엇을 바꿨는지 한 줄로 주고 전수 탐색을 시킨다.
특히 **물타기(`bypass_entry_gates=True`)에 적용해야 하는지**와
**외부 상태 대조라면 반대 방향**을 반드시 답하게 한다.

## 5. `null-hypothesis` 호출 — 무효 반증 🔴

**반드시 구현한 대화와 분리해서 호출한다.** 같은 컨텍스트면 "이게 왜 작동해야 하는지"에 이미 물들어 있다.

ON/OFF A/B가 **실제로 갈리는지** 수치로 확인받는다. 안 갈리면 스위트가 전원 통과해도 무효다.

## 6. 검증 — `verify` 스킬

19개 스위트 전부. 진입 게이트를 건드렸으면 **#12(실거래 재생)와 #15(아카이브 리플레이)까지** 반드시.
매수·매도 로직이면 **#11 감사가 마지막 관문**이다.

## 8. 커밋 + 이관 문서

- 의미 단위 커밋. 민감정보(`config.ini`/`settings.py`/`.env`) 확인.
- CLAUDE.md 「다음 할 일」에 **"다음 거래일에 처음 도는 것"**과 **장중 확인 항목**을 적는다.
- 근거 강도를 정직하게: `결함` / `강` / `중` / `약` / `판정 불가`.
- 🔴 **롤백 방법을 반드시 한 줄로** 남긴다.

## 되돌릴 때

**한 번에 하나씩.** 근거가 약한 것부터.
⚠️ 세트로 움직여야 하는 것들:
- 익절캡 ↔ 본전스톱/확정익절 (캡만 올리면 "캡 도달분 77% 본전 회귀"가 재현된다)
- 손절 `-4.5%` ↔ `RESCUE_ADD_OBSERVE_FLOOR` (같아지면 '손절 대신 추가매수'가 원리적으로 죽는다)
- 눌림 슬롯 ↔ 1A 슬롯 (1A를 8로 두면 6칸을 독식한다)
