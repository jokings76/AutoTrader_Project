장중 관찰이다. 🔴 **어떤 파일도 수정하지 마라.** 실계좌가 돌고 있다.

`market-watch` 에이전트를 호출해서 아래를 받아라. 로그 원문을 이 대화로 끌어오지 말고
**판정 결과만** 받는다(로그 트롤링이 수만 토큰이다).

에이전트에게 전달할 것:

1. `CLAUDE.md` 「다음 할 일」의 **「🔬 … 장중에 반드시 볼 것」 표**를 먼저 읽고
   **그 항목으로** 판정하라고 지시할 것 (체크리스트는 날짜마다 바뀐다).
2. 로그는 반드시 **`logs/autotrader.log*`** — 로테이션 포함.
3. `수동 매도 감지` 건은 손익 0의 가짜값이니 승률·평균에서 제외하고 `무손익 N`으로 따로.
4. REST 호출 금지(봇과 토큰 충돌).

받은 뒤 사용자에게 이렇게 정리하라:

```
■ <HH:MM> 봇 정상/이상
■ 오늘: 매수 N · 청산 N · 보유 N · 실현(DB 추정) <원>
■ 체크리스트: <항목별 정상/이상/판정 불가 — 근거 한 줄씩>
■ 🔴 즉시 조치: 없음 / <무엇을>
```

## 🔴 이상이 발견되면

**장중에 코드를 고치지 마라.** 대신:

1. 무엇이 잘못됐는지, 어떤 롤백 상수 한 줄로 되돌릴 수 있는지 사용자에게 보고한다.
2. 정말 급하면 **봇 정지**(`STOP_SIGNAL`) → 수정 → 재기동 순서다.
   08-10·08-12에 실제로 이렇게 했다(정지~재기동 2~3분).
3. 상수는 프로세스 기동 시 로드되므로 **재시작해야 반영된다**
   (`setattr`은 재시작 없이 먹지만, 파생 상수와 `pos["stop_rate"]`는 예외).

되돌리는 법은 `CLAUDE.md` 「즉시 되돌리는 법」, 근거는 `docs/EXPECTED_VALUES_RATIONALE.md`.
