# 장전 스캔 수동 관심목록 (premarket_scan.py가 매일 08:30에 읽는다)
#
# 사용법
#   · 한 줄에 종목코드 하나(6자리). `#` 뒤는 주석.
#   · 저장만 하면 다음 날 08:30 스캔에 자동 반영된다(봇 재시작 불필요).
#   · 여기 넣은 종목은 눌림이 아니어도 판정 결과가 리포트에 남는다 —
#     "왜 후보가 아닌지"를 봐야 감이 생긴다.
#
# ⚠️ 이 파일은 **관측 전용 스캐너만** 읽는다. 매매 로직은 이 파일을
#    쳐다보지도 않는다 — 여기 넣는다고 봇이 사지 않는다.
#    봇이 사려면 그 종목이 HTS 조건검색(주도주상위/눌림목자동/돌파자동매매용)에
#    편입돼야 한다.
#
# 예시:
#   005930   # 삼성전자 - 눌림 들어가는지 보고 싶음
#   073240   # 금호타이어
